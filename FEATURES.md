# E-commerce Store

## 1. Project Overview

The E-commerce Store is a web-based application that allows 
customers to browse and purchase products online. It also
provides an admin panel to manage products and the store catalogue.

## 2. Problem Statement

Customers need a convenient way to browse and purchase products
online. Store administrators also need an organised system to
manage product information and customer orders.

This project provides an online shopping platform where 
customers can register, log in, browse products, search for 
items, add products to their shopping cart and place orders. 
Administrators can manage products and categories efficiently.

## 3. User Roles

### Customer
- Register and log in.
- Browse available products.
- Search for products.
- View product details and images.
- Add and remove products from the cart.
- Place orders.
- View order history.

### Admin
- Log in to the admin panel.
- Add new products.
- Edit existing products.
- Delete products.
- Manage product categories.
- View customer orders.

## 6. Project Goal

The main goal is to develop a user-friendly online shopping 
application that makes purchasing products easier for 
customers and product management simpler for administrators.
